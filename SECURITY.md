# Security

## Reporting a vulnerability

Report it privately at
[github.com/heydianaai/diana/security](https://github.com/heydianaai/diana/security) —
choose **Report a vulnerability**. Only the maintainers see it.

Please do not open a public issue, pull request or discussion for a vulnerability.

Include what you can: the version (`diana --version`), the system, what an attacker
can do, and the steps to reproduce it.

## Supported versions

The latest release. Fixes ship in a new release, not as patches to older ones.

## What to expect

- An acknowledgement within a week.
- An assessment, and a fix or a reason there will not be one.
- Credit in the release notes when it ships, unless you would rather not.

Please give us a reasonable time to ship a fix before you publish.
