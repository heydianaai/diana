# Diana

Downloads for [Diana](https://heydiana.ai), the seat beside your coding agents.

Get the latest from the [releases](https://github.com/heydianaai/diana/releases/latest) or from
[heydiana.ai/download](https://heydiana.ai/download). Installed copies update themselves when you
click **Update available**; each update is signed, and the app refuses one that is not.

This repository holds releases only.
